# 0.3.6 — компактное окно и обход по кадрам

- Окно 640×340, с увеличением высоты только при необходимости для системного масштаба. Поля ADB/test-apks, разрешение визита, кнопки «Проверить профиль», «Стоп», «Отчёт». Статус показывает причину остановки; без итогового всплывающего окна.
- Лог 0.3.5: frame-budget на первом кадре, три строки; реклама — 1, avatar_unready — 2. Профиль не открывался. Сам счётчик не различал скрытый, отсоединённый и неинтерактивный Avatar.
- Не больше одной строки за кадр. Между кадрами хранится только индекс, ссылки освобождаются; перед действием текущая строка, Entry и User проверяются заново. Если строка сама превысит 100 мс, тест всё ещё остановится. Общие пределы не увеличены.
- Avatar используется как изображение-источник для штатного обработчика, не как кнопка. Для него не требуется UserInteractionEnabled; видимость, цепочка родителей и совпадение User обязательны. Добавлены avatar_hidden/avatar_noninteractive; совпадение личности не ослаблено.
- Локально: 197 unit-тестов, 68 Frida/C ABI сценариев, 12 metadata-only регрессий. Среди новых — неинтерактивный/скрытый/отсоединённый Avatar, несовпадение User и медленные строки. Windows и реальный MuMu проверяются отдельно.

Скачай артефакт **Dvk-rootless-profile-navigation-0.3.6-windows-x64** из успешного запуска Actions. Распакуй, открой загруженную сетку поиска на #4 / 5563, запусти EXE с прежними ADB и test-apks. Оба MuMu должны быть запущены. APK не переустанавливай; #0 / 5555 защищён. Один визит может быть виден в гостях; сообщений нет.

После теста пришли **rootless-profile-navigation-0.3.6.json** рядом с test-apks. При неизвестном результате вернись в поиск вручную, не повторяй тест вслепую. Открытие профиля на реальном MuMu пока не подтверждено.
