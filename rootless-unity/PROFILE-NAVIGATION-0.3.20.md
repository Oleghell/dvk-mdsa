# 0.3.20 — одно приветствие

На #4 / 5563 вручную открой нужный личный чат. Оба MuMu включены, прежняя test-apks. Нажми «Отправить «Привет 🙂» — один раз». Не меняй экран. Это отдельная отправляющая кнопка; «Проверить чат» остаётся без отправки.

Фиксированный текст: Привет 🙂. Нет имитации набора, случайных сообщений, обхода анкет, смены городов или сбора контактов. Вызывается штатный OnSendText на подтверждённом UI-потоке. До вызова — два свежих согласованных замера пустой полностью загруженной истории, проверка того же User/Chat/CM/controller, видимости, актуальности модели, стабильности draft и IsInputEnabled. Непустой/неизвестный чат не отправляется.

Обработчик вызывается максимум один раз. До него устанавливается latch; ошибка или потеря ответа не запускает повтор. Файл .dvk-one-greeting.lock в test-apks блокирует повтор между запусками. Он снимается автоматически только при проверенном ответе, что вызова не было. При неизвестном исходе не удаляй блокировку и не повторяй: сначала проверь чат вручную. Доставка не подтверждается: messages_sent остаётся null после попытки, а send_handler_returned означает только возврат обработчика.

Отчёт: rootless-one-greeting-0.3.20.json рядом с test-apks. Пришли его и скажи, появилось ли одно приветствие. Android-отправка этой версии ещё не проверена. #0/5555 защищён, APK не переустанавливаются, путь ADB прежний. Нет автоматического старта и галочки. Изменение касается только отдельной отправляющей кнопки; доказанная проверка истории сохранена.
