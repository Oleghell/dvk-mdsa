# Dvk APK Installer 1.0.0

Отдельная Windows-программа; Python устанавливать не нужно.

1. Запусти MuMu и останови автоматизацию на выбранных портах.
2. Открой DvkApkInstaller.exe.
3. Выбери adb.exe из своей папки platform-tools.
4. Выбери папку test-apks с base.apk и split-*.apk из одного комплекта.
5. Вставь нужные порты, например 5557, 5559, 5567. Можно по одному на строку.
6. Нажми «Установить» и дождись результатов в журнале.

Установка по очереди, только на явно введённые локальные порты. Применяется install-multiple -r, без удаления приложения, root или автоматического запуска. Совместимость APK, подписи и версии проверяет Android; ключ -r не обходит несовместимую подпись и не гарантирует сохранение данных при любых ошибках устройства. Не смешивай файлы разных комплектов.

«Стоп» прекращает очередь после текущей операции, не обрывает начатую установку. При таймауте установки результат неизвестен и автоматического повтора нет; сначала проверь устройство. Ошибка одного порта не мешает следующим.

Программа не читает переписку, не подключается к Supabase и не использует ключи или Telegram. Настройки основной DvkAssistant не меняет. Установщик не исправляет конфликт одинаковых портов на двух ноутбуках — это отдельное обновление основной программы.

Готовый EXE и SHA-256 публикуются отдельным релизом apk-installer-v1.0.0. EXE не подписан сертификатом издателя. Загружай его только из своего репозитория и проверяй опубликованную контрольную сумму.
