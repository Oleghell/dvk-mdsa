# 0.3.19 — чтение истории draft-диалога

Оба MuMu включены. На #4 / 5563 вручную открой тот же личный чат → прежняя test-apks → «Проверить чат». До завершения не меняй экран. Отчёт: rootless-open-chat-state-0.3.19.json рядом с test-apks.

Причина остановки 0.3.18 установлена по реальному отчёту: metadata ready, привязка чата подтверждена, IsActual=true, IsDraftChat=true, HasMessagesCM=true; остановка chat-draft на этапе model. Менеджер истории и Count ещё не читались. Ошибочным был запрет чтения любой draft-модели, а не проверка getter или поиск экрана.

Теперь стабильный IsDraftChat=true не препятствует чтению существующего MessagesCM. Draft не приравнивается к пустоте. Для пустого/непустого результата по-прежнему нужны актуальная модель, существующий CM/DataField, полностью загруженная история без загрузки, три согласованных Count в каждом из двух замеров с интервалом минимум 1 с, неизменная привязка и видимый экран. Count=0 с LastMessage остаётся противоречием. Флаг draft должен совпадать до/после замера и между двумя засчитываемыми замерами. Переход draft → обычный чат сбрасывает первый замер; постоянное изменение внутри замера даёт неизвестный результат. Неполная история и отсутствие CM никогда не считаются пустотой.

Это исправление подтверждённого барьера в коде. Состояние загрузки и реальный Count этого Android-чата пока неизвестны; успех 0.3.19 на устройстве ещё не подтверждён. Даже пустая доступная история не доказывает отсутствие удалённых сообщений в прошлом.

Нет UI-действий, ввода, отправки, чтения текстов или контактов. #0/5555 защищён, APK не переустанавливаются; прежний ADB, без галочки и автозапуска. Сохранены ограничения времени/вызовов/потока и освобождение handles. Профильные действия изменены только по номеру версии.

Проверки: 271 unit-тест и 47 нативных C/Frida сценариев. Draft проверяется отдельно для пустой/непустой, загружающейся/неполной истории, отсутствующего CM, изменения внутри замера и перехода между замерами. CI: Linux, Windows, упакованный GUI. Реальный Android-тест ещё требуется.
