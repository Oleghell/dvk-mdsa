# 0.3.24 — короткие порции поиска и подготовка ответов

## Исправление frame-budget
В реальном отчёте 0.3.23: три анкеты проверены, две команды отправки выполнены; на четвёртой попытке поиск остановился до открытия профиля. Теперь подробно проверяется не более одной новой ячейки за вызов. Медленное чтение может перенестись на следующий кадр, только пока профиль не открывался и постоянные привязки ещё не переданы. Не более восьми переносов; затем остановка. Жёсткий бюджет 100 мс, общий лимит вызовов, паузы 1 с и запрет повторной отправки не увеличены/не отключены. Сильная постоянная задержка всё ещё приводит к безопасной остановке. scan_yields/scan_slices видны в JSON.

Прежний автопроход: сетка поиска на #4 → «Автопроход · до 10 анкет». Непустые чаты и друзья 50+ пропускаются. Отчёт rootless-automatic-pass-0.3.24.json. Блокировки прошлых отправляющих запусков не снимаются обновлением.

## Подготовка ответов — пока без живых автоответов
В коде готовы SQLite-учёт не более 10 явно привязанных диалогов, вопросы «Как дела?)»/«Как настроение?)», запрос Telegram/WhatsApp, остановка при отказе/неоднозначности, распознавание добровольно присланного контакта, очередь уведомлений. Резервирование каждого действия фиксируется ДО вызова: после сбоя/таймаута автоматического повтора нет. Переход к следующему этапу требует увидеть собственное сообщение в истории; возврат обработчика не считается доставкой. При негативном или нетекстовом ответе — ручная проверка, не шаблон «Супер».

Эта логика протестирована с собственным тестовым backend. Реального Android-адаптера чтения входящих/выбора отслеживаемого чата пока НЕТ; автоматический ответ кнопкой не запускается. SQLite-учёт ещё не заполняется существующим автопроходом. 0.3.23 не сохраняла ID: прежние 10 диалогов из её JSON восстановить нельзя. Нельзя автоматически подменить их новой десяткой.

Для подключения нужен один полный инвентарь типов. На #4 открой один из уже начатых личных чатов (лучше с входящим ответом), оставь оба MuMu запущенными. Нажми «Подготовить ответы · без отправки». Пришли rootless-reply-metadata-0.3.24.json рядом с test-apks. Эта кнопка читает ТОЛЬКО определения типов/методов/полей: не тела сообщений, не ID/имена/контакты, не значения объектов; не нажимает и не отправляет. Статус chat-runtime-ready подтверждает сбор определений, НЕ готовность автоответов.

## Telegram
Кнопка «Telegram» открывает локальные поля токена и Chat ID. Токен шифруется Windows DPAPI для текущего пользователя, хранится в %LOCALAPPDATA%/DvkRootless/telegram.dpapi, не в GitHub, test-apks или JSON-отчёте. Сначала сохранение, затем отдельная кнопка «Отправить один тест». Автоуведомления из Android ещё не подключены. Ошибка сети — неизвестный исход, без автоматического повтора. Не отправляй токен в чат и не прикладывай файл настроек.

Будущая SQLite-база содержит привязки и контакты, но не полный текст переписки; её нельзя прикладывать к публичному issue. Диагностические сводки — только счётчики. Никаких новых людей сверх десяти, прокрутки, смены города или имитации человеческой печати.
