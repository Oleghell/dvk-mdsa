1. Распакуй архив в отдельную папку на том же Windows, где сохранены ключи MoreLogin.
2. Запусти START_CHECK.cmd обычным двойным щелчком, без администратора.
3. Пришли появившийся morelogin-format-check.json.

Это диагностика, не исправление EXE. Нужен интернет. Ключи читаются из Windows DPAPI и используются только для двух запросов к api.morelogin.com: авторизация и чтение данных выбранного Cloud Phone ID 1732535802182343. Телефон не запускается, команды ADB/SSH не исполняются, приложения и настройки не меняются. Отчёт содержит только типы полей и обезличенную структуру команды, без ключей, паролей, IP и имени SSH-пользователя. Не запускай под записью PowerShell Transcript.
