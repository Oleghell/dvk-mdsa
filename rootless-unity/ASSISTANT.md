# DvkAssistant

## Текущий статус — общий цикл ещё не готов

Главное окно сокращено до **Старт / Стоп / Настройки**. Тестовые кнопки,
ручные проходы и технические определения убраны из основного интерфейса.
Пути и настройки Telegram находятся в «Настройках».

**Эта сборка проверяет только навигацию:** фиксированный переход
«анкеты → список личных диалогов → те же анкеты». Отдельные диалоги ещё не
обходятся, цепочки и общий непрерывный цикл не запускаются. Сообщения не
отправляются, Telegram и чтение переписки не используются.

Метод `MainTabsController.DV.IMainTabsController.SwitchToTab(System.Type,Boolean)`,
типы `MessagesTabController` и `ChatsViewController` найдены в присланных
определениях. Каждая сигнатура заново проверяется в работающем приложении.
Используются семантические контроллеры, не координаты, OCR или номер вкладки.
Переход допускается только с прикреплённого видимого экрана, без неизвестных
модальных окон. Возврат успешен только к тому же экземпляру поиска.
Синтетические тесты не подтверждают работу на реальном MuMu.

### Что сделать для продолжения

1. После успешной сборки распакуй `DvkAssistant-windows-x64` в отдельную папку.
2. В «Настройках» проверь ADB и прежнюю папку `test-apks`. Переустановка не нужна.
3. На **MuMu №4** открой поиск анкет. Закрой фильтры/диалоги. Нажми **Старт**.
4. Должен открыться список личных сообщений, затем снова тот же поиск анкет.
   Во время проверки не управляй экраном. Повторного запуска и отправок нет.
5. Откроется `%LOCALAPPDATA%/DvkAssistant/`. Пришли только
   **messages-navigation-check.json** — и при успехе, и при остановке.

«Стоп» запрещает дальнейшие действия, но не отменяет уже выполненный переход.
При сбое экран может остаться в личке — вернись к анкетам вручную.
При неизвестном экране или сигнатуре нет угадывания кликов и повторов.
Отчёт содержит только фиксированные статусы/категории экранов, счётчики и
проверки готовности; нет имён, контактов, ID людей и текстов переписки.
Закреплённые APK и установка сверяются существующим preflight; устройство №0
не используется. Исходный offline-сборщик определений сохранён для разработки,
но «Старт» больше не создаёт `messages-navigation-definitions.json`.

## Целевой алгоритм

Город + онлайн → новые подходящие анкеты → приветствия → личка → продолжение
цепочек при новых ответах → другой город. Старые диалоги также проверяются
по интервалу. Переходы должны проверять текущий экран и фактический результат.
Нет сообщений без ответа, повторов при неизвестном исходе и сброса журналов.

## Telegram: только свой контакт и имя

В библиотеке автоматической цепочки обычные входящие больше не создают
Telegram-уведомлений. Пересылаются только имя проверенного текущего собеседника
и контакт, который он явно сообщил как свой. Отдельный контакт без пояснений
принимается только как ответ на предложение перейти в мессенджер.
Чужие/цитируемые контакты, отрицание принадлежности, отказ и неясность не
вызывают передачи. Достоверность принадлежности не гарантируется распознаванием;
неоднозначный случай остаётся для ручного разбора.

Имя читается проверенным `User.get_Name` только после сверки ID и двух
стабильных снимков той же переписки. Нет извлечения контактов из анкеты.
Полная переписка не пересылается. Контактная очередь хранится отдельно в
`chain_contact_outbox`, только под Windows DPAPI, без plaintext fallback.
Перед сетевым вызовом попытка фиксируется; ошибка/таймаут не разрешают повтор.
Старые обычные уведомления из `chain_notifications` не отправляются.

Контактная библиотека и чтение имени проверены синтетически, но ещё не
подключены к общему циклу. Текущая проверка навигации ничего в Telegram не
отправляет. Настройки бота сохраняются только локально через DPAPI:
`%LOCALAPPDATA%/DvkRootless/telegram.dpapi`.

## Для разработчика

Прежний интерфейс сохранён в `assistant_legacy.py` только для регрессионных
тестов; он не является точкой входа EXE. Рабочий entry point — `assistant_app.py`.
Журналы просмотров, резервов отправки и этапов не удаляются и не сбрасываются.

```text
python rootless-unity/run_unit_tests.py
python rootless-unity/smoke_one_chat_name.py ./one_chat_fixture.so
python rootless-unity/smoke_dialog_navigation.py ./dialog_fixture.so
```
