# DvkAssistant 1.1.1 — MuMu №4

## Запуск

1. Распакуй весь архив в новую папку, включая `config`. Не удаляй прежние базы
   в `%LOCALAPPDATA%\DvkAssistant`: журнал защищает от повторных отправок.
2. В «Настройках» укажи ADB и test-apks. По умолчанию: 5 подходящих анкет
   за порцию, проверка диалогов через 30 секунд после прохода.
3. «Старт» — анкеты и ответы; «Только ответы» — без поиска анкет.
   Подтверждение разрешает сообщения на весь запуск, отдельных окон отправки нет.
   При открытии EXE действий нет. «Стоп» отменяет дальнейшие действия,
   но не отзывает уже начатую отправку.

## Что делает программа

- Полный режим набирает порцию подходящих анкет. Друзей 50 и больше или непустой
  чат — пропуск, место занимает другой человек. Случайные города берутся из
  `config/cities.json`, приветствия — из `config/greetings.json`.
- Через 120 секунд после окончания порции запускается следующая, с другим
  случайным городом. Операции последовательные, без параллельных нажатий.
- Между порциями проверяет диалоги: сначала непрочитанные, затем прочитанные
  активные отслеживаемые чаты. Если ты прочитал входящее, но не ответил,
  программа продолжит текущий шаг. Уже обработанное повторного ответа не вызывает.
  Если ты ответил сам вне журнала, нужна проверка — цепочка не угадывает продолжение.
- Цепочка: приветствие → ответ человека → вопрос о делах → ответ человека →
  предложение Telegram/WhatsApp → ожидание добровольно присланного контакта.
  Отказ завершает чат. Проверяются доступные видимые строки, не весь архив.
- Не меняй экран во время работы. При неизвестной отправке повтора нет;
  программа оставляет чат для проверки и показывает причину остановки.

## Groq и свои правила

В «Настройки → Groq» введи API-ключ локально, выбери модель, включи Groq и сохрани.
По умолчанию Groq выключен. «Тест Groq» использует вымышленную переписку.
Ключ защищается Windows DPAPI, в отчёты и исходники не попадает.

**Свои правила: `config/groq-rules.txt` рядом с EXE.** Можно открыть кнопкой
«Открыть правила Groq». Меняй стиль и формулировки, сохраняй в UTF-8. Новые запросы
сразу читают изменённый файл; готовые черновики не переписываются. Базовые проверки,
отказы и порядок шагов сохраняются. Пустой/повреждённый/отсутствующий файл блокирует
запрос с `groq-rules-unavailable`.

В Groq передаются правила и до 12 фрагментов по 300 символов из проверенного чата.
ID, имя профиля и вложения не отправляются; контакты и ссылки маскируются,
но свободный текст может содержать другую личную информацию. Не вписывай секреты
в правила. Условия и тарификация API — по твоему аккаунту Groq.
Ответ краткий, по текущему шагу; смысловые ошибки модели возможны. Ошибка API
останавливает цикл без запасного шаблона. ИИ-черновики сохраняются с шифрованием DPAPI.

## Telegram и отчёты

В «Настройки → Telegram» укажи токен и Chat ID, сохрани и нажми «Тест Telegram».
Отдельные переключатели: добровольно присланные контакты и причины ошибок/пауз.
При недоступности бота уведомление не гарантируется; причина остаётся локально.

Папка отчётов: `%LOCALAPPDATA%\DvkAssistant`.
- `last-monitor.json` — текущий цикл и точные причины остановки.
- `last-run.json` — последняя порция начального прохода.

В окне — краткий этап и основные счётчики. Наличие исходящего в истории не
подтверждает доставку. В отчётах нет текстов переписки и ключей.

Новые функции проверены синтетическими тестами, не живым аккаунтом Groq/MuMu.
Первый запуск после обновления проверь на тестовом собеседнике.
