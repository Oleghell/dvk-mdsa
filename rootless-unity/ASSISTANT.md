# DvkAssistant 1.2.0 — MuMu №4

## Запуск

1. Распакуй весь архив в новую папку, включая `config`. Не удаляй прежние базы
   в `%LOCALAPPDATA%\DvkAssistant`: журнал защищает от повторных отправок.
2. В «Настройках» укажи ADB и test-apks. По умолчанию: 5 подходящих анкет
   за порцию, проверка диалогов через 30 секунд после прохода.
3. «Старт» — анкеты и ответы; «Только ответы» — без поиска анкет.
   Подтверждение разрешает сообщения на весь запуск, отдельных окон отправки нет.
   При открытии EXE действий нет. «Стоп» отменяет дальнейшие действия,
   но не отзывает уже начатую отправку.

## Что делает программа

- Полный режим набирает порцию подходящих анкет. Друзей 50 и больше или непустой
  чат — пропуск, место занимает другой человек. Случайные города берутся из
  `config/cities.json`, приветствия — из `config/greetings.json`.
- Через 120 секунд после окончания порции запускается следующая, с другим
  случайным городом. Операции последовательные, без параллельных нажатий.
- Между порциями проверяет диалоги: сначала непрочитанные, затем прочитанные
  активные отслеживаемые чаты. Если ты прочитал входящее, но не ответил,
  программа продолжит текущий шаг. Уже обработанное повторного ответа не вызывает.
  Если ты ответил сам вне журнала, нужна проверка — цепочка не угадывает продолжение.
- Цепочка: приветствие → ответ человека → вопрос о делах → ответ человека →
  предложение Telegram/WhatsApp → ожидание добровольно присланного контакта.
  Отказ завершает чат. Проверяются доступные видимые строки, не весь архив.
- Не меняй экран во время работы. При неизвестной отправке повтора нет;
  программа оставляет чат для проверки и показывает причину остановки.

## ИИ / ключи: Groq или OpenRouter

1. Настройки → **ИИ / ключи**: включи ИИ и выбери сервис.
2. Groq: `qwen/qwen3.8-27b`. Бесплатный OpenRouter:
   **`minimax/minimax-m3.1-flash:free`**.
Второй проверенный вариант: `dots-studio/dots-3-note-preview:free` (Preview). Модели из списка проверены коротким
   API-тестом этой версии, но будущая доступность не гарантируется.
3. Вставь ключ выбранного сервиса локально и нажми **«Тест ИИ»**.
   Тест сразу использует введённый ключ, до сохранения. Пустое поле означает
   сохранённый ключ. Три вымышленных сценария: вопрос, контакт, отказ.
4. **«Сохранить ключ ИИ»** сохраняет его независимо от Telegram. Общая кнопка
   **«Сохранить»** сохраняет модель, сервис и переключатели.
5. Ключи Groq и OpenRouter хранятся раздельно, через Windows DPAPI.
   В исходниках, архиве и отчётах ключей нет. Пустое поле не удаляет старый ключ.
   При смене сервиса несохранённое поле очищается. ИИ по умолчанию выключен.

`groq-key-unavailable` — недоступен сохранённый ключ, а не модель. Вставь ключ,
проверь и сохрани заново под текущим пользователем Windows. Не удаляй базу.

OpenRouter: только `:free`, цена токенов ограничена нулём, платной замены нет.
В запросе запрашивается политика `data_collection=deny`. Если бесплатная модель
перегружена (429) или нет совместимого провайдера (404), работа останавливается
с причиной. Приватность не ослабляется, модель/сервис молча не меняются.
Бесплатная квота ограничена аккаунтом, поэтому бесконечная бесплатная работа
не гарантируется. Кнопка теста тоже расходует квоту.

## Свои правила ИИ

**`config/groq-rules.txt`** рядом с EXE — общий файл для обоих сервисов.
Открывается кнопкой **«Открыть правила ИИ»**. Сохраняй UTF-8, новые запросы
прочитают изменения без перезапуска. Готовые черновики не переписываются.
Проверки, отказы и порядок шагов сохраняются. Не записывай в правила секреты.

В выбранный сервис передаются правила и до 12 фрагментов по 300 символов;
для OpenRouter — также провайдеру модели. ID/имя профиля и вложения не отправляются,
контакты маскируются, но другая личная информация может остаться в свободном тексте.
Ответ краткий; смысловые ошибки модели возможны. При ошибке API запасного ответа
нет. ИИ-черновики сохраняются с шифрованием DPAPI, неизвестные отправки не повторяются.

## Telegram и отчёты

В «Настройки → Telegram» укажи токен и Chat ID, сохрани и нажми «Тест Telegram».
Отдельные переключатели: добровольно присланные контакты и причины ошибок/пауз.
При недоступности бота уведомление не гарантируется; причина остаётся локально.

Папка отчётов: `%LOCALAPPDATA%\DvkAssistant`.
- `last-monitor.json` — текущий цикл и точные причины остановки.
- `last-run.json` — последняя порция начального прохода.

В окне — краткий этап и основные счётчики. Наличие исходящего в истории не
подтверждает доставку. В отчётах нет текстов переписки и ключей.

API Groq/OpenRouter проверены вымышленными сценариями, цикл — синтетическими
тестами. Это не проверка новой версии на реальном MuMu.
Первый запуск после обновления проверь на тестовом собеседнике.
