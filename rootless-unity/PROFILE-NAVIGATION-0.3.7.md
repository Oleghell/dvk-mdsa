# 0.3.7 — паузы 1 с и счётчик друзей

- 0.3.6 подтверждена реальным отчётом на #4: профиль открыт, личность проверена, возврат выполнен, 109/109 ссылок освобождены.
- Пауза не меньше 1 секунды перед первым открытием, между открытием и возвратом, после возврата перед итоговой проверкой. Ожидание не блокирует главный поток и не расходует лимит активных кадров/managed-вызовов. «Стоп» срабатывает без ожидания паузы. Прежние бюджеты не увеличены.
- После проверки профиля ищется ровно один из двух точных getter-методов User: get_FriendsCount или get_FriendCount. Требуется экземплярный метод без аргументов, точный владелец и Int32 без byref; другие методы не вызываются. Это проверка поддержки, а не утверждение, что эти getter существуют в текущем APK.
- Счётчик читается дважды у проверенного User, после чтения снова проверяется профиль. Только стабильное значение 0–1000000 попадает в friends_count; friends_eligible означает count < 50. При отсутствии, неоднозначности, неподдерживаемой сигнатуре или нестабильном значении — неизвестно, а не ноль. При смене профиля число не публикуется. friends_status/source объясняют результат.
- Значение пока диагностическое: его нужно сверить с интерфейсом приложения, в том числе после загрузки профиля. Наличие getter и стабильность значения не доказывают свежесть серверных данных. Чат не открывается, сообщения не отправляются, новые люди автоматически не перебираются.
- Компактное окно сохранено; результат показывает число друзей или «неизвестно». JSON содержит только технические поля и запрошенный счётчик, без имён, ID, переписки, списков друзей и контактов.

Скачай **Dvk-rootless-profile-navigation-0.3.7-windows-x64** из успешного запуска Actions. Запуск как прежде: оба MuMu включены, на #4 / 5563 загруженная сетка поиска, прежние ADB и test-apks. APK не переустанавливай; #0 / 5555 не изменяется. Один визит может быть виден в гостях.

Пришли **rootless-profile-navigation-0.3.7.json** рядом с test-apks. При остановке после открытия вернись в поиск вручную. Эта версия на реальном MuMu ещё не проверена.

Проверка в Linux: 200 unit-тестов, 81 уникальный Frida/C ABI сценарий и 12 metadata-only регрессий. Интервалы открытия/закрытия/возврата измерялись монотонными часами C-стенда; проверены отмена во время ожидания, 0/49/50 друзей, неизвестный/невалидный счётчик и смена профиля. Это не проверка Windows/MuMu.
