# DvkAssistant 1.0.1

## Изменения

- Убраны отдельные кнопки ручного режима из главного окна. Журналы и привязки сохранены.
- «Старт»: один прежний начальный проход, затем мониторинг только отслеживаемых диалогов.
- «Только ответы»: мониторинг без новых анкет. Между проверками окно остаётся на списке диалогов.
- Интервал проверки настраивается: 30–3600 секунд, по умолчанию 120. Проходы последовательные.
- Каждая отправка требует отдельного подтверждения. Отказ/тайм-аут ставят работу на паузу,
  без повторного предложения по таймеру. Продолжение — новым явным запуском.
- При ошибке, неизвестной отправке или сбое записи отчёта мониторинг останавливается.
- Отдельный last-monitor.json: счётчики вызовов отправки, возвратов обработчика и новых
  наблюдений исходящих. Старые наблюдения не суммируются повторно; доставка не заявляется.
- Приветствия больше не считаются доставленными по возврату обработчика. Неизвестное число
  попыток при обрыве цикла помечается отдельно.
- Таймер смены городов и повторные обращения к новым анкетам не добавлены.

## Проверка и ограничения

Добавлены синтетические проверки мониторинга, остановки, пауз, отчётности и навигации
в список диалогов без открытия чата. Native ABI-тесты работают с собственными фикстурами,
без аккаунтов и Android. Windows-сборку проверяет CI; её результат смотри в Actions.
Новая версия ещё требует отдельного прогона на реальном MuMu №4 с тестовым собеседником.
Не удаляй существующую базу: она защищает от повторных отправок.
