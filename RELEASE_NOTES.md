# MuMu 1.3.7

## Быстрый непрерывный цикл MuMu

- В полном режиме нет обязательного ожидания остатка 120 секунд: обработаны доступные диалоги → поиск новых анкет → следующая проверка диалогов. После продуктивного прохода допускается одна свежая перепроверка входящих. Лимит времени проверяется между завершёнными проходами; устройство не прерывается посреди проверки/отправки. Отложенные из-за API/истории и ручные проверки не объявляются отвеченными и не блокируют переход к поиску.
- Первое приветствие в новой анкете разрешается без имитации печати. Сохраняются проверка пустого чата, журнал, атомарная межаккаунтная защита от повторов и проверка привязки. Последующие ответы печатаются с прежними 35 словами/мин; статус показывает оставшееся время, без текста сообщения.
- В обработке открытого диалога убрана искусственная пауза 5 секунд после отправки и между проверками исходящего. Сразу выполняется свежее проверенное чтение; после подтверждения и контрольного чтения — возврат к списку. Неподтверждённая отправка не повторяется, число проверок ограничено.
- Кэш диалогов сканируется до четырёх строк за кадр вместо одной, с запасом 40 мс до прежнего бюджета 100 мс. Проверки модели, заголовка, непрочитанного, привязки и одноразового перехода сохранены. Статус отдельно показывает поиск чата, чтение и сканирование следующей порции, а не оставляет надпись «чат 3» на всём поиске.
- «Только ответы» не начинает поиск анкет: при отсутствии входящих остаётся отдельный проверочный интервал. Загрузка истории, ответы API и реальные переходы устройства занимают время; убрать их ожидание без потери проверок нельзя. Лимиты API, загрузки и неизвестные отправки не обходятся.

- Исправлено продолжение после call-limit в поиске: только если лимит достигнут до открытия анкеты/чата, без запроса разрешения, попытки отправки и ошибки очистки, запускается независимая проверка поиска и смена города. Число циклов ограничено прежними 200; лимиты вызовов/кадров не увеличены. После действий, смены привязки или неизвестной отправки повтор не выполняется. В отчёт добавлены этап, счётчики и признаки действий без персональных данных. Ожидание ещё не готовой анкеты не опрашивает модель на каждом Unity callback.
- Главное окно уменьшено с 760×430 до 600×350 (минимум 560×330), таблица рассчитана на пять MuMu. Подписи больше не обещают обязательный двухминутный простой. Проверка упакованной Windows-версии дополнительно контролирует видимость и границы элементов.

Только ветка MuMu. MoreLogin не изменён. Базу и журналы не удалять, APK не переустанавливать. Нумерация Telegram сохранена: 5563 (1), 5557 (2), 5559 (3), 5561 (4), 5565 (5). Реальные MuMu новой версией ещё не проверены.

- Лимит полной проверки сборки увеличен с 12 до 35 минут: расширенный набор нативных тестов не помещался в старый бюджет Linux. Проверки Windows/Linux сохранены; публикация по-прежнему требует успешного завершения обеих проверок и упаковки.
- Нумерация Telegram сохранена: 5563 (1), 5557 (2), 5559 (3), 5561 (4), 5565 (5).

При исчерпании лимитов API содержательный ответ не гарантируется; выдуманный шаблон вместо сложного ответа не отправляется. Реальные MuMu этой версией в тестовой среде не проверены.

После четырёх неудачных чтений чат откладывается на 60 секунд только после подтверждённого возврата из того же чата; другие продолжаются. Частичная история не используется, неподтверждённые отправки не сбрасываются и не повторяются. Порции чтения уступают кадр раньше, если остаётся мало времени на перепроверку.
- Telegram не называет отсутствие текста в уведомлении ошибкой чтения. Для прочитанных, но неотвеченных сообщений учитываются ожидающие квитанции ответа. Смешанный отказ ИИ различает непрошедшие проверку ответы и исчерпанные лимиты; проверки содержания не отключены, квоты не обходятся.
- Все Telegram-уведомления процесса помечены: 5563 (1), 5557 (2), 5559 (3), 5561 (4), 5565 (5). Другие порты остаются без выдуманного номера.

Только ветка MuMu. MoreLogin не изменён. Базу и журналы не удалять, APK не переустанавливать. Неподтверждённые старые отправки остаются на ручной проверке. Синтетические тесты не заменяют проверку на реальных MuMu.

# MuMu 1.3.4

## Исправления MuMu 1.3.4

- Порция анкет завершается без промежуточных заходов в личку. После порции — 120 секунд активной работы в диалогах, проверка каждые 5 секунд. Проверки привязки, остановка и печать 35 слов/мин сохранены.
- Входящие получают отдельные квитанции ответа: прочтение/возврат не подтверждают отправку. Подтверждение требует точного исходящего из журнала в проверенной истории. После отправки — дополнительная проверка новых входящих; неотвеченный остаток не скрывается отметкой «прочитано».
- После подтверждённого контекстного ответа новые реплики могут получать следующий ответ. Старые отправки архивируются; неизвестные попытки никогда не сбрасываются/не повторяются. Контакт уточняется не более одного раза; новые отказы соблюдаются.
- Короткий выбор «Ватсап макс», «Вацап» распознаётся в этапе ожидания добровольного контакта. Вопрос/отказ или упоминание неработающего приложения не считаются согласием. Не придумываются личная биография и контакты.
- Все доступные ключи Groq предшествуют бесплатному OpenRouter. После отказа всех сервисов только для простого нового приветствия/эмодзи на начальном шаге разрешено проверенное «Как настроение?». Сложные вопросы, возражения, отказ и запрос контакта этим шаблоном не заменяются. Квоты провайдера не обходятся.
- Полная проверенная история: до 128 сообщений, до 8192 символов каждое, до 65536 суммарно. Перед новой отправкой нужно менее 128 сообщений, чтобы оставалось место для проверки исходящего. Чтение частями по 4 сообщения, проверка всех заголовков до тел, два совпадающих полных снимка. Обрезанная история не используется; более крупные/меняющиеся чаты безопасно откладываются. Это НЕ безлимитный архив и НЕ восстановление непроверенной хронологии.
- Telegram различает подтверждённый ответ и пропуск. Новый неотвеченный пакет не скрывается старым уведомлением; при реальном пропуске сохраняется снимок перед проверенным возвратом. Неизвестная доставка Telegram не повторяется.
- Компактное окно 760×430, порты и статусы остаются видимыми; полная причина в отчётах. Общая база и защита от повторных приветствий между MuMu сохранены.

Только ветка MuMu; MoreLogin не изменён. Реальные устройства ещё требуют проверки. Не удаляй базу/журналы и не переустанавливай APK. Если в старом чате исходящие невозможно однозначно связать с журналом, он остаётся на ручной проверке — эта защита не отключена.

# MuMu 1.3.3

## Исправления 1.3.3

- Чтение сообщений разбито на короткие порции по 4 сообщения за кадр: сначала проверяются заголовки всех сообщений, затем читаются тела. В конце сравниваются два полных снимка; частичная история не попадает в ИИ и отправку. Между порциями повторно проверяется тот же аккаунт, собеседник и чат. Несколько входящих передаются вместе с исходящими сообщениями, а не только последняя реплика. Лимиты полного снимка (до 20 сообщений и 16 384 символов) пока сохранены; слишком большая история откладывается, не обрезается.
- `frame-budget` на финальной перепроверке привязки теперь допускает ограниченное повторное чтение с нуля. При исчерпании попыток — только проверенный возврат и отложенная проверка, без отметки «обработано». Изменение личности/чата остаётся причиной остановки.
- Выбор города: установка текста и проверка/запуск поиска идут в разных кадрах. Медленный, но завершённый вызов установки текста не повторяется. Повторяется только чтение после него; ошибки/неопределённый результат мутации не маскируются.
- Порядок ключей Groq → OpenRouter, диагностика 1.3.2, фото с причиной пропуска и защита от повторной неизвестной отправки сохранены. Внешний сервис может остаться недоступным — в таком случае чат откладывается, а не считается отвеченным.
- Запуск из уже открытого диалога: только при точном распознавании контроллера и двойной проверке аккаунта/собеседника/чата выполняется один возврат в личку. После него список подтверждается заново. Текст переписки при таком возврате не читается, сообщения не отправляются; неизвестные экраны и смена привязки не обходятся.
- HTTP 429/503: числовой `Retry-After` учитывается отдельно для каждого ключа (не более суток), остальные ключи проверяются сразу в обычном порядке Groq → OpenRouter. Это не снимает квоты сервиса. Ключи и тела ошибок не попадают в сборку или отчёт.

Только MuMu. MoreLogin не изменён. Не удаляй базы/журналы и не переустанавливай APK.

# MuMu 1.3.2

## Исправления 1.3.2

- При уведомлении о пропуске снимок открытой переписки проверяется по аккаунту/собеседнику/чату до и после захвата и делается **до выхода**. После проверенного возврата Telegram получает **одно фото с подписью** — текст собеседника и краткую причину. Чужой/непроверенный экран не отправляется. Он не помечается полностью обработанным. **Это не безлимитное чтение:** действующие ограничения полного снимка сохранены, обрезанная история не используется для отправки. Постоянно слишком большой чат может оставаться отложенным и требует отдельного разбора.
- После недоступности всех ИИ-ключей не фиксируется завершение обработки чата; повторная проверка не раньше чем через 60 секунд. Генерация может повторяться, неопределённая отправка — никогда.
- Причины отказов ИИ сохраняются для каждого сервиса и номера ключа: лимит, сеть, авторизация, непроверенный ответ, ограничение токенов; видны также ключи на временной паузе. Самих ключей и тел ошибок API нет. Краткая причина приходит в Telegram вместо одинакового сообщения для всех сбоев.
- Верхняя граница генерации Groq увеличена с 220 до 1024 токенов: короткий лимит мог обрывать ответ модели. Это не отменяет лимитов API и проверок итогового сообщения (до 240 символов).
- Для MuMu 5563 сохраняется старый путь `%LOCALAPPDATA%\DvkAssistant`; остальные отчёты лежат в `devices/<порт>`. Используй уже существующую кнопку «Открыть отчёты выбранного MuMu».

MoreLogin не изменён. Не удаляй базы/журналы, не переустанавливай APK. Доступность внешних сервисов и успешное чтение каждого большого диалога не гарантируются.

- Сканирование моделей диалогов обрабатывает одну строку за кадр. Исчерпание бюджета до открытия чата допускает ограниченное продолжение чтения того же индекса; после попытки действия повтор запрещён. Проверки экрана, идентичности, лимита вызовов и общего времени сохранены.
- Telegram /today, /yesterday, /week, /month показывают новые добровольно присланные контакты и подтверждение приёма уведомления Telegram. /week — последние 7 календарных дней, /month — 30; дни по часовому поясу компьютера. /city — топ-20 городов поиска за всё время, где дали номер. Это не подтверждённый город проживания.
- Учёт начинается с обновления: старые контакты не выдумываются. Номера, ники, имена и тексты не сохраняются в статистике; события уникальны по разговору. Для старых разговоров без записанного города выводится «Неизвестен». Подтверждение Telegram не означает прочтение адресатом.
- Команды работают, пока программа открыта и сохранены настройки Telegram. Ответы только в заданный Chat ID. Бот не управляет телефоном, не запускает циклы; неизвестный результат ответа не повторяется. Один потребитель на токен на компьютере: для одновременного независимого MuMu/MoreLogin используйте разные токены ботов.
- Режим ответов загружает только приветствия и больше не требует корректного cities.json. Поиск анкет продолжает проверять список городов; пользовательские файлы не заменяются и не обрезаются автоматически.
- Алгоритм, список файлов и SHA256 общего ядра закреплены в shared-core.json. main — источник; проверяемая синхронизация переносит только перечисленные файлы в mumu. Данные, ключи, APK и платформенные интерфейсы не копируются.
- Сборка MoreLogin использует один анализ зависимостей для трёх EXE. ZIP сжимается один раз, загружается без повторного сжатия; кешируются зависимости и бинарный кеш PyInstaller, не настройки/ключи/исходный APK. Публикация разрешена только после всех проверок. Очередь GitHub не позволяет гарантировать сборку за две минуты.

Работа на реальном устройстве после этих изменений требует проверки. Чужие и неподтверждённые чаты не открываются; неизвестные отправки не повторяются. APK переустанавливать не нужно, базу не удалять.

с last_navigation=null ещё не установлена; исправление работы на реальном MuMu
