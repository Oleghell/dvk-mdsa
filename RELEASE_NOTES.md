# DvkAssistant 1.0.0

Итоговая версия по ТЗ: одна кнопка «Старт» ведёт всю цепочку.

## Что нового

- **«Старт» = ответы + новые анкеты.** Сначала открываются непрочитанные чаты,
  где уже идёт цепочка, затем — новые анкеты: «Только онлайн», случайный город,
  друзей меньше 50, пустой чат, приветствие после подтверждения.
- **Смена города**, когда новые анкеты закончились; недавние города не повторяются.
- **Цепочка в непрочитанных чатах:** любой ответ → «Как дела?)»/«Как настроение?)» →
  любой ответ → предложение Telegram/WhatsApp → контакт → уведомление боту.
- **«Только ответы»** — отдельная кнопка без новых анкет.
- **«Тест Telegram»** и **«Очистить историю анкет»** в настройках.
- Неподтверждённое сообщение предлагается снова при следующем «Старте».
- Единый номер версии, понятный итог в окне, отчёт `last-run.json`.
- Убрана устаревшая кнопка «Привязать чат для чтения».

## Безопасность

Каждое сообщение — только после подтверждения. Неизвестные отправки и уведомления
не повторяются. В Telegram — только имя и контакт, присланный самим человеком.

## Статус готовности

Автотесты и сборка Windows проходят. На устройстве ранее проверены навигация,
чтение непрочитанных и ручная цепочка до предложения мессенджера.
**Новый «Старт» целиком, приём контакта и поиск анкет в этой сборке на реальном
MuMu ещё не запускались** — первый запуск сделай с тестовым собеседником.

Скачай `DvkAssistant-1.0.0-windows-x64.zip`, распакуй и запусти `DvkAssistant.exe`.
Инструкция — `README.md` внутри архива.
