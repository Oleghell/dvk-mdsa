# MoreLogin 2.0.0-beta.3

- На Windows заменён HTTP-транспорт Open API: системный .NET HttpWebRequest через Windows PowerShell, соответствующий успешной локальной проверке пользователя (HTTP 200 / auth-ok).
- APP ID, API Key и временные токены передаются только по приватному stdin/stdout, не через командную строку и не через временные файлы. Фиксированный код, no-profile, без shell, без отключения проверки сертификатов, прокси и HTTP-перенаправлений.
- Только получение токена и чтение ADB-параметров выбранных ID. Не включаются ADB, питание телефонов или установка APK.
- В настройках добавлена проверка уже сохранённых DPAPI-ключей без запуска телефонов. Отчёт last-api-check.json не содержит секретов/тела ответа.
- Ошибки API по-прежнему сохраняются; защита от дублей и общая база не меняются. Старые ключи не сбрасываются.
- MuMu и отложенные задачи цикла/статистики не изменены.

Исходная причина HTTP 403 в urllib не доказана: успешная отдельная проверка позволила выбрать проверенный на компьютере пользователя механизм запроса. Реальная работа новой программы с API/SSH/Android 14–15 ещё требует проверки. Нужен совместимый приватный Gadget APK; обычный ДругВокруг автоматически не меняется.
