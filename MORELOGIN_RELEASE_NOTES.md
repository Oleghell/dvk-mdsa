# MoreLogin 2.0.0-beta.5

Исправление обработки SSH-ответа Open API после диагностического отчёта пользователя.

- Поддержаны DNS-адреса SSH, совпадающие с отдельным adbIp выбранного Cloud Phone. Разрешение DNS проверяется; приватные, смешанные и некорректные ответы блокируются до подключения. Соединение устанавливается с уже проверенным IP без повторного разрешения имени.
- Поддержаны кавычки, раздельные/слитные -o и известные параметры совместимости OpenSSH (HostKeyAlgorithms / PubkeyAcceptedAlgorithms / PubkeyAcceptedKeyTypes, StrictHostKeyChecking, UserKnownHostsFile). Эти параметры не исполняются и не отключают проверку закреплённого SSH-ключа приложения. Команды, ProxyCommand, LocalCommand, неизвестные настройки и посторонние назначения по-прежнему запрещены.
- Причины ошибок адреса, параметров и назначения разделены. В last-connection.json автоматически добавляется обезличенная структура: типы полей, число аргументов и только известные имена опций. Пароль, исходная команда, SSH-пользователь и адрес не записываются.
- Исправлена совместимость самопроверки диагностического скрипта с экранированием JSON Windows PowerShell 5.1.
- Сборка и независимые тесты выполняются параллельно; перед публикацией обязательны все проверки. Реальное время зависит от очереди GitHub.
- MuMu, общая база, журналы, настройки и защита от повторной отправки не меняются. Отложенные задачи цикла/статистики не включены.

Проверка API и SSH не подтверждает совместимость Gadget на реальном телефоне. Программа ничего не устанавливает и не удаляет. Совместимый приватный Gadget APK по-прежнему обязателен. Нужна проверка на телефоне пользователя.
