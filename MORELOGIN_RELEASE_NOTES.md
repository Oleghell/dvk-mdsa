# MoreLogin 2.0.0-beta.1

Предварительный перенос алгоритма MuMu 1.2.16 на MoreLogin Cloud Phone.

- Явный новый список Cloud Phone ID в программе, параллельные изолированные процессы.
- APP ID / Secret Key, официальный Open API, DPAPI; проверяемые SSH-туннели для документированной схемы Android 14–15.
- Одна общая локальная SQLite-база: общие резервы анкет и раздельные журналы чатов по ID.
- Изменившийся SSH-ключ, неизвестная отправка и потеря привязки не обходятся.
- MuMu сохранён отдельно в ветке mumu. Старые ветки архивируются тегами перед удалением.

ВАЖНО: реальная совместимость с Cloud Phone Android 14–15 ещё не проверена. Нужна уже установленная совместимая тестовая копия приложения с Gadget и соответствующий приватный test-apks; обычный APK не адаптируется автоматически. Сначала один телефон, режим «Только ответы».
