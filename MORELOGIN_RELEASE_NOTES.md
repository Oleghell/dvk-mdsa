# MoreLogin 2.0.0-beta.2

Исправлена диагностика Open API и пустая таблица проверки подключения.

- Ошибка больше не затирается сообщением об окончании проверки.
- Каждый введённый Cloud Phone ID получает состояние, включая ошибку запуска.
- Разделены HTTP, DNS, TLS, тайм-аут, сеть и неверный формат ответа; указан этап авторизации или получения ADB-параметров.
- Показываются безопасные числовые HTTP/MoreLogin-коды, без текста сервера и секретов.
- Отчёт last-connection.json сохраняется отдельно от журналов чатов.
- До трёх попыток только для временных сетевых ошибок и HTTP 429/500/502/503/504. Отправка сообщений не повторяется.
- Схема запросов сверена с официальным Cloud Phone Open API. Причина ошибки на компьютере пользователя ещё не установлена; новая диагностика позволит её определить.

База, ключи DPAPI, APK и ветка mumu не изменены. Отложенные исправления цикла/статистика Telegram не включены.

ВАЖНО: Android 14–15 и реальный Cloud Phone не проверены. Нужна совместимая тестовая копия приложения с Gadget. Обычный APK не адаптируется автоматически. Не удаляйте приложение для устранения ошибки API.
