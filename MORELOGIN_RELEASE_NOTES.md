# MoreLogin 2.0.0-beta.4

Добавлен документированный прямой ADB MoreLogin без SSH для Android 12/15.

- При отсутствии SSH-команды или точной прямой команде adb connect используются IP, порт и код подключения из ответа Open API для выбранного Cloud Phone ID.
- Код передаётся по ADB smart-socket, не через командную строку или временные файлы. Поддержан числовой код, публичный IPv4; неизвестный формат отклоняется.
- Прямой ADB использует отдельный локальный relay каждого телефона; ядро по-прежнему привязано только к своему endpoint, общий список устройств не сканируется.
- Проверка подключения выполняет вход по коду и проверяет boot UUID/загрузку Android, без запуска рассылки, изменения APK, питания или переключателя ADB.
- SSH сохранён с прежней проверкой ключей. Ошибка SSH не включает скрытый прямой fallback.
- Общая SQLite-база, журналы неизвестных отправок, API-ключи и MuMu не меняются. Отложенные задачи цикла/статистики не включены.

ВНИМАНИЕ: прямой ADB не является зашифрованным SSH-туннелем. Используйте доверенную сеть. Реальная совместимость новой сборки с телефоном пользователя ещё не проверена; нужен совместимый приватный Gadget APK. Программа ничего не устанавливает и не удаляет.
