# MoreLogin 2.0.0-beta.6

Добавлен отдельный явный установщик DvkCloudInstaller.exe и кнопка «Установить Gadget».

- Один Cloud Phone ID за операцию. Используются существующие DPAPI-ключи и проверенный SSH-ключ. Ручные SSH-команды и передача ключей в чат не нужны.
- Проверяются точные хеши частного split-комплекта, локальная конфигурация Gadget с токеном, SDK 34/35 и основная архитектура arm64-v8a. Работа Gadget на реальном Android 15A ещё не подтверждена.
- Отдельные блокировки выбранного ID и boot UUID исключают одновременную установку и цикл на этом телефоне. Все ADB-команды имеют явный изолированный loopback endpoint; MuMu не выбирается и общий сервер ADB не перезапускается.
- Перед установкой есть подтверждение. Для существующего приложения сначала пробуется обновление install-multiple -r без удаления. Только точный INSTALL_FAILED_UPDATE_INCOMPATIBLE разрешает предложить замену.
- Удаление требует отдельного ручного ввода ТОЧНОГО Cloud Phone ID и успешного сохранения/проверки исходных APK. Резервные APK НЕ сохраняют аккаунт, вход, переписку или данные приложения. Требуется 4 ГБ свободного места. Новая установка всё равно может завершиться ошибкой.
- Исходные APK сохраняются в phones/<ID>/apk-backups; отчёт без секретов — phones/<ID>/last-install.json. Перед удалением сохраняется маркер; при ошибке/таймауте нет автоповтора или автоматического восстановления. Остановка не откатывает выполненные действия.
- Нет root, отключения SELinux, обхода подписи, автоматического входа, запуска приложения, Gadget attach или сообщений. После установки пользователь сам открывает приложение и входит, затем проверяет «Только ответы» на одном телефоне.
- APK и токены в публичный релиз НЕ включены. Нужно выбрать частную папку test-apks. МуМу и отложенные задачи циклов/статистики не изменены.

Это предварительная сборка. Синтетические тесты и offline self-check Windows не заменяют реальной проверки установки, входа и Gadget на Cloud Phone пользователя.
