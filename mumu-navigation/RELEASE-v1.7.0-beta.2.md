# MuMu 1.7.0-beta.2 — строгий нативный режим

Экспериментальная версия, не полная замена всех сценариев ДругВокруг.

## Что изменено

- GUI запускает только строгий Accessibility/UiAutomation режим.
- Публичный MCP предоставляет ровно пять инструментов: status, ui_inspect, ui_diagnostics, ui_find, ui_action.
- Скриншоты, OCR, CV, координатные tap/swipe, посимвольная IME и старые инструменты отправки заблокированы на уровне MCP и ADB транспорта.
- `allow_fallback` принимает только `false`. Нативный click всегда передаёт `allow_coordinate_fallback=false`; без ACTION_CLICK — отказ, без альтернативной инъекции.
- Запуск устанавливает только один проверенный control-helper.apk. Клавиатура не меняется; старые помощники не устанавливаются и не удаляются.
- Расширенная диагностика временно включает REPORT_VIEW_IDS, INCLUDE_NOT_IMPORTANT_VIEWS, RETRIEVE_INTERACTIVE_WINDOWS, читает только окна drug.vokrug и восстанавливает прежние флаги. Чужие окна не обходятся. Пароли и их описания скрываются.
- Диагностические узлы не используются для действий. Ограничения: до 32 перечисленных окон плюс активное, до 2000 узлов и глубина 64. Неполный отчёт не доказывает отсутствие элементов.
- Исправлена ранняя регистрация модуля при запуске EXE: локальные исключения больше не должны превращаться в безликую Internal read error из-за двойного импорта.
- Существующий журнал и лимиты сохранены. Неизвестные исходы не сбрасываются. Никакой автоматической отправки сообщений.

## Как запустить

1. Остановите старый мост, распакуйте **весь новый ZIP в отдельную папку**. Не смешивайте APK и EXE разных версий.
2. Откройте ДругВокруг в MuMu, запустите MuMu-navigation.exe и нажмите «Включить MuMu».
3. Прочтите новое согласие: нативный доступ без изображений и смены клавиатуры.
4. Передайте новый адрес подключения агенту. Bearer-ключ — только через защищённый запрос подключения, не в чат.
5. Первый удалённый вызов — `mumu_ui_diagnostics {}`. Для диагностики начинать новый тест анкет не нужно.
6. Для поиска: `mumu_ui_find {"selector":{"text":"Написать"},"timeout_ms":2000,"allow_fallback":false}`.

Если установка помощника отклонена — остановка без удаления/переустановки ДругВокруг. Старую клавиатуру, если она осталась выбранной после beta.1, переключите вручную в настройках Android: beta.2 её не меняет.

## Известное ограничение — Unity

На ранее подключённом устройстве список анкет раскрыл только 7 контейнерных узлов, включая drug.vokrug:id/unitySurfaceView, без отдельных карточек/кнопок. Нативный EditText чата ранее был доступен. **Расширенный скан beta.2 на этом устройстве ещё не выполнен.**

Если он также не обнаружит нужные элементы, эта версия откажет в соответствующем действии. Она не будет угадывать координаты. Присутствие какого-либо редактора/кнопки не доказывает доступность всей бизнес-цепочки, личности собеседника или пустого чата.

Для полностью объектного управления скрытым Unity UI потребуются изменения Accessibility в самом приложении, разрешённая инструментированная сборка с Poco/AltTester или официальный поддерживаемый API. Установка Appium поверх того же Android дерева не создаёт отсутствующие узлы.

Исторические OCR/CV и fixed-layout исходники и тесты оставлены для регрессии/сравнения, а не как активный fallback. Внутренние совместимые тесты явно включают `native_only=False`; обычный GUI не предлагает такой переключатель. Подписанный помощник содержит старые операции для совместимости исходников, но строгий транспорт их не пропускает. Это отказ от визуальных методов в новой рабочей цепочке, не заявление об удалении каждой исторической функции из репозитория.

## Проверки и границы

Синтетические тесты проверяют нативные CLICK/SET_TEXT, неоднозначность, смену состояния, парольную редакцию, флаги диагностики, разные разрешения/DPI и отказ на непрозрачном нарисованном элементе без изображений/tap. Они не доказывают работоспособность всех экранов настоящего ДругВокруг. Детали исследования — NATIVE_ONLY_RESEARCH.md.
