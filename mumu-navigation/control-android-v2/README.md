# Подписанный выпуск control/keyboard v2 — 1.6.0

Новые package IDs и новое signature permission изолированы от v1. Старые APK не меняются и не удаляются. Приватный постоянный ключ и пароль НЕ находятся в этом каталоге или CI. `pinned/` содержит только публичные подписанные APK в base64 и контрольные суммы исходников/DEX/APK/сертификата.

`build.sh` компилирует исходники без подписи; `pack-control.py` сравнивает пересобранный DEX и восстанавливает точные подписанные APK; `verify-signature.py` криптографически проверяет подпись и сертификат. CI тестирует эти же подписанные APK, а не переподписанные копии.

`test-emulator.py` проверяет ввод на искусственном стенде; `test-guarded-emulator.py` — три отдельных нажатия при изменении пикселей только внутри поля. Оба запрещены вне одноразового CI-эмулятора. Ключи, APK искусственных приложений и пользовательские данные в релиз не попадают.

Для будущего обновления нужен тот же приватный ключ из отдельной резервной копии владельца. Не заменять сертификат молча и не переписывать старые pins без проверки исходников/DEX/подписи.
