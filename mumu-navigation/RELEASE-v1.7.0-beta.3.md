# MuMu 1.7.0-beta.3 — диагностика Unity без OCR

Экспериментальная версия для следующего шага после Accessibility-сканирования. Она **не заявляет управление скрытыми кнопками Unity**.

## Новый инструмент

`mumu_ui_unity_diagnostics {}` — строго только чтение, без параметров:

- версия установленного `drug.vokrug`, Android-флаги `debuggable` и `test_only`;
- архитектуры, поддерживаемые Android, отдельно от ABI найденных библиотек;
- чтение ZIP-каталогов основного установленного APK и split APK;
- ограниченный список признаков: `libunity.so`, `libil2cpp.so`, известные Mono-библиотеки, Unity `global-metadata.dat` и `Assembly-CSharp.dll`;
- отчёт о полноте проверки, неизвестном/смешанном результате и причинах неполноты без раскрытия файловых путей.

**Содержимое записей APK не извлекается и не исполняется. APK наружу не передаётся.** Пути берутся только из Android PackageManager для одного фиксированного пакета. Произвольный путь, имя пакета, shell-команда, OCR или root через инструмент не принимаются.

Не читаются переписка, токены, настройки и закрытое хранилище ДругВокруг. Проверяется только имя пакета активного окна; дерево с текстами чата для этой команды не обходится. Не запускаются Frida, Gadget, su, отладчик или код из приложения. Нет изменения APK, подписи или защит приложения.

## Как трактовать результат

- `il2cpp_indicated` — найдена библиотека IL2CPP в установленном пакете. Это ещё не доказательство её загрузки или доступности Unity-объектов.
- `mono_indicated` — найдена известная Mono-библиотека; наличие Unity оценивается отдельно.
- `il2cpp_metadata_only` — найдена только запись метаданных, без доказательства нативного backend.
- `managed_assemblies_only` — есть признак Unity managed assembly, но backend не определён.
- `mixed_indicators` — признаки конфликтуют/смешаны; нельзя автоматически выбирать runtime.
- `unity_backend_unknown` — признак Unity есть, backend неизвестен.
- `not_identified` — подходящие записи не найдены в полностью проверенных установленных APK. Это не доказательство отсутствия Unity, скачиваемых модулей или кода в иных местах.
- `unknown_incomplete` — проверка неполная; делать вывод об отсутствии backend нельзя.

Во всех случаях `runtime_objects_access=not_tested`, `sdk_integration_status=not_assessed`. Ни `debuggable=true`, ни найденная библиотека сами по себе не разрешают/не доказывают безопасную инструментализацию или UI-действие.

Ограничения: основной APK плюс до 32 splits, до 150000 ZIP-записей суммарно, до 128 маркеров; кооперативный лимит перечисления 4 секунды. Открытие локального ZIP само по себе не прерывается этим таймером, общий ADB-таймаут остаётся ограниченным. Ошибки чтения и превышение лимитов дают неполный результат, без root/fallback.

## Установка

1. Остановите beta.2. Если после старого визуального режима выбрана специальная клавиатура, вручную верните обычную в настройках Android: новая версия её не переключает.
2. Распакуйте **весь ZIP beta.3 в отдельную папку**, не смешивая EXE/APK разных версий.
3. Откройте ДругВокруг в MuMu. Запустите `MuMu-navigation.exe` → «Включить MuMu».
4. При запуске проверяется именно установленный пакет, без обхода переписки и без действий. Недоступные APK дают неполный отчёт, а не скрытую эскалацию.
5. Передайте агенту новый MCP-адрес. Bearer-ключ — только через защищённое окно подключения.
6. Агент вызовет `mumu_ui_unity_diagnostics {}` и выберет следующий этап по реальному отчёту. Для чтения не нужен новый тест анкет.

Запуск устанавливает только проверенный control-helper.apk прежней подписи, без удаления ДругВокруг и без смены клавиатуры. Старый журнал и лимиты сохраняются.

## Строгий нативный режим сохранён

Публично доступны шесть инструментов: status, ui_inspect, ui_diagnostics, ui_unity_diagnostics, ui_find, ui_action. OCR, CV, изображения, координатные клики и старые инструменты отправки не предоставляются. Исторические исходники сохранены для регрессии, но не как рабочий fallback.

Статус больше не описывает строгий режим как старую визуально проверяемую отправку. Отправка не предоставляется; личность собеседника нативно не подтверждена. Исторические записи журнала при этом не изменяются.

## Проверки

- Реальный Java-сканер проверяется на синтетических ZIP/APK: splits, IL2CPP/Mono/metadata-only, нерелевантные имена, повреждённые/недоступные файлы, повторяющиеся пути и лимиты.
- Host-валидатор отвергает лишние поля, файловые пути, неверные счётчики, попытки объявить доступ к объектам доказанным, изображения или root.
- Android CI проверяет PackageManager и чтение синтетического APK. В нативной тестовой программе специально есть **только фиктивная запись метаданных**, что должно дать metadata-only, а не «Unity-объекты доступны».
- Доступность объектов установленного пользовательского ДругВокруг ещё не проверена этой версией.
