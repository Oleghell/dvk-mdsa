# DvkAssistant

Помощник для ДругВокруг в MuMu №4. Рабочая ветка:
`feature/android-ui-hierarchy`. Один EXE, три кнопки:
**Старт / Стоп / Настройки**.

## Важно: текущая сборка проверяет только переход в личку

Общий непрерывный цикл ещё **не включён**. По присланным определениям добавлен
фиксированный маршрут **анкеты → список личных диалогов → те же анкеты**.
«Старт» выполняет только эту ограниченную проверку в MuMu №4, не открывает
отдельные переписки, не читает их и **ничего не отправляет**, включая Telegram.
Результат синтетического стенда не является подтверждением на реальном MuMu.

После успешного **Build DvkAssistant** скачай `DvkAssistant-windows-x64`,
распакуй отдельно, проверь ADB и прежнюю папку `test-apks` в настройках.
Открой поиск анкет на №4, закрой фильтры/диалоги и нажми «Старт» один раз.
Не переключай экран во время работы. После проверки откроется папка с
`messages-navigation-check.json` — нужен только этот файл.
При остановке/ошибке экран может остаться в личке; автоматического отката нет.
APK, базы, переписка и токены в отчёт не попадают. Устройство №0 не используется.

## Целевой цикл

1. Выбрать город из `config/cities.json`, проверить «Только онлайн».
2. Проверять новые анкеты, приветствовать подходящих с `< 50` друзьями.
3. После исчерпания города открыть личку и обработать новые ответы.
4. Перейти к следующему городу, периодически проверяя старые диалоги.
5. Telegram: только имя и добровольно сообщённый свой контакт, один раз.

Обычные ответы не вызывают Telegram-уведомлений. Неясные/чужие контакты не
пересылаются. Секреты и контактная очередь защищаются Windows DPAPI;
неизвестный исход отправки не повторяется. Сообщения не отправляются только
потому, что старые сообщения снова стали видны.

[Инструкция и точные границы готовности](rootless-unity/ASSISTANT.md).
Исходный код прежних проверенных режимов сохранён; журналы не удаляются.
Нативные и unit-тесты находятся в проекте для разработки, не в главном окне.
